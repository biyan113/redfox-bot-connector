# RedFox 数据研究

1. 确认用户要查询的平台、关键词、时间范围与调用预算。查询可能按次收费，先控制数量。
2. 优先使用 MCP 的 `search_douyin_users` 搜索抖音账号；其他平台和接口先查 https://redfox.hk/apis 的实际方法、路径、请求参数及价格，再使用 `redfox_post`。此工具只支持官方 `/story/api/` 的 POST 接口；其他方法需直接按照官方文档调用。
3. 根据真实返回结果整理账号、作品、链接、时间和互动数据，保留来源与采集时间。缺失字段标记未知，不捏造数据；不同平台指标不一定可直接比较。
4. 需要分页时使用文档规定的游标，设置页数上限。失败先报告原因，不盲目重试，避免重复计费。
5. 用户要求导出时，将结果保存为 JSON 或 CSV，明确字段含义。监控、定时、Webhook 需要独立调度或服务，勿声称本 Skill 已实现。
6. API Key 只从环境变量或本地配置读取，不在输出、日志或分享文件中暴露。
